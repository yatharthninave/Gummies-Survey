## 🛠️ Tech Stack & Technical Implementation

The **Gummy Lab** application is a lightweight, high-performance web-based survey platform designed for seamless user interaction and analytics tracking.

### Core Technologies
* **Frontend:** Built with vanilla **HTML5** and custom styling/scripts for fast load times and low overhead.
* **Hosting & Deployment:** 
  * Primary deployment on **[Vercel](https://gummies-survey.vercel.app/)** for continuous integration and zero-config global CDN delivery.
  * Secondary hosting via **GitHub Pages** automated using **GitHub Actions** (`.github/workflows`).
* **Analytics & Tracking:** Integrated with **Google Analytics** (`gtag.js`) to capture user interaction flow, drop-off rates, and response metrics in real time.
